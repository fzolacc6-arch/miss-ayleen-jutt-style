# Miss Ayleen — Personal Profile

A responsive, animated, pink glassmorphism profile website made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and profile content
- `style.css` — responsive layout, glass effects and animations
- `script.js` — welcome screen, visualizer toggle, sparkle particles and cursor effects
- `assets/ayleen-avatar.jpg` — anime profile artwork
- `assets/pink-night-bg.jpg` — background artwork

## Run locally
Open `index.html` in a modern browser. No build step, package manager or server is required.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

All asset paths are relative, so the site works from a GitHub Pages project URL.

## Notes
- The music-style section is an animated visualizer, not an audio track.
- The Discord card opens the Discord user URL. The arrow button copies the displayed ID where clipboard access is available.
- Google Fonts are loaded online; system fallbacks are included.
